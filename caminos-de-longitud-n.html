Desde
Hasta

Cómo leerla: si A es la matriz de adyacencia (1 si dos nodos están conectados, 0 si no), el teorema clásico dice que (Aⁿ)[i,j] es el número de recorridos de longitud n entre el nodo i y el j — pueden pasar dos veces por el mismo nodo. Por eso la diagonal de A² ya no es cero: A²[i,i] cuenta, para cada vecino de i, el recorrido de ida y vuelta. La lista de la derecha, en cambio, sólo cuenta caminos simples (sin repetir nodos), que es lo que normalmente imaginamos como "un camino". Ambos coinciden cuando la red es un árbol o cuando n es pequeño, pero se separan en cuanto aparecen ciclos.
